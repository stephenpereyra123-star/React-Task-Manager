# To-Do List App

A simple To-Do List application built using React and Tailwind CSS. Users can add and delete tasks, set due dates, and schedule times to stay organized.

## Features

- Add new tasks
- Delete tasks using the trash icon
- Set due dates and times
- Dynamically display tasks

## What I Learned

This project helped me practice:

- Managing React state using arrays and objects
- Using `.map()` to render tasks dynamically
- Using `.filter()` to remove tasks
- Passing props between React components
- Updating the UI when state changes

## Technologies Used

- React
- JavaScript
- Tailwind CSS
- Vite
